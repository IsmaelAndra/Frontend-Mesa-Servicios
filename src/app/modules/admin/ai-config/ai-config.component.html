Reglas y comportamiento esperado

Lo que el asistente siempre debe y nunca debe hacer

Estas reglas se anteponen a las instrucciones de cada acción, así que ganan a las que trae el sistema. Sirven para fijar el tono, los límites y los pasos obligatorios de la institución.

Si lo dejas vacío, el asistente usa solo sus instrucciones propias, sin reglas adicionales.

Apagar una acción la bloquea en el servidor, no solo esconde el botón.

Asistente de IA

Proveedores soportados: GEMINI (recomendado, incluye free tier) y cualquier API compatible con Chat Completions de OpenAI como OPENAI, AZURE_OPENAI, ANTHROPIC u OLLAMA. Con esto se habilitan las sugerencias de respuesta y el resumen de tickets para agentes y administradores.
