Buenas prácticas de seguridad

  • El client secret se cifra (AES-256-GCM) con una clave maestra que no se guarda en la base de datos.
  • El backend nunca devuelve el client secret al frontend; solo indica si está configurado.
  • Dejar el campo Client Secret vacío conserva el valor existente.
  • El access token se mantiene en memoria y se reutiliza hasta su expiración; no se persiste ni se registra en logs.
