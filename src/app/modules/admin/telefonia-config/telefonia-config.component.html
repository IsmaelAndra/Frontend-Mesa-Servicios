Cómo ponerlo en marcha

  1. En la UCM (API Configuration): activar la API, crear su usuario, marcar solo dialExtension y permitir solo la IP del servidor interno.
  2. Aquí: URL, usuario y clave de la API, Generar token y activar.
  3. En el servidor interno: copiar la carpeta puente-telefonia, crear el .env con MESA_URL y PUENTE_TOKEN, y ejecutar instalar-windows.ps1 como administrador (necesita Node.js 20).
  4. Poner la extensión a cada persona en Usuarios → Editar.

No se abre ningún puerto: el puente solo hace conexiones de salida.
